# 바로얌 영상팀 파일명 제작

촬영 폴더명, 색보정 완료 파일명, 프리미어 프로젝트명, 메타 업로드 파일명을 만드는 도구입니다.

## 사용 방법

1. 사이트에서 폴더명 / 색보정 파일명 / 프로젝트명 / 메타 업로드용 중 하나를 선택합니다.
2. 날짜와 각 드롭다운을 선택하거나 직접 입력합니다.
3. 복사 버튼 또는 ⌘/Ctrl + Enter로 완성된 이름을 복사합니다.
4. 폴더명 화면에서는 촬영용 빈 폴더 구조를 ZIP으로 다운로드할 수 있습니다.

## 외부 작업자와 공유

GitHub Pages로 배포된 사이트는 로그인이나 저장소 편집 권한 없이 사용할 수 있습니다. 저장소의 Settings → Pages에서 접속 주소를 확인할 수 있습니다.

입력, 드롭다운 편집 내용, 최근 기록은 각자의 브라우저에만 저장됩니다. 다른 사람의 설정이나 저장소 원본은 바뀌지 않습니다. 동일한 목록을 공유하려면 드롭다운 편집 → 설정 내보내기 / 가져오기를 이용하세요.

## 기본 규칙

- 폴더: `(날짜)_(브랜드명)_촬영원본`
- 색보정: `(브랜드명)_(촬영 유형)_(중간설명)_(최종설명)_(버전)`
- 프로젝트: `(날짜)_(브랜드명)_(제목)_(버전)_(작업자)`
- 메타: `(날짜)_(브랜드명)_(제목)_(주소구)_(B 코드)_(H 코드)_(C 코드)_(버전)_(작업자)`

날짜는 한국 시간 기준 오늘이 기본값이며 YYMMDD 형식입니다. 실제 영상 파일명 변경과 프리미어 프로젝트 저장은 작업자가 직접 수행해야 합니다.

## 배포

의존성이나 빌드 과정 없이 `index.html` 하나로 실행됩니다. GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시하도록 설정합니다. `index.html`을 수정하고 커밋하면 사이트에 자동 반영됩니다.
